## Reading and maintaining the register

**Class** describes the intended relationship to the reference. **Match** means matching task behavior. **Browser** means a browser equivalent for the same user purpose. **Extension** means a separate product capability. **Observation** means that the exact result still needs evidence. Suffixes split a feature when the classification or delivery stage changes. A source ID is defined under [sources](#sources).

**State** tracks delivery independently. *Tested* identifies software behavior exercised on the cited Linux builds. Linked tests describe the cases exercised. An OBS number identifies a pending comparison with the Mac reference. *Partial* identifies a working increment with a named outstanding delivery or field check. *Deferred* identifies an optional addition outside current delivery. Joe records any accepted exception with its scope and impact. [Release and field evidence](READINESS.md)

Milestones with two or more stages give the first usable subset followed by completion or hardening. A dependency refers to the named capability at the stage shown. M0 fixtures and contracts allow M1 interaction work before the persistent services exist. Concrete evidence and owners for edge cases appear under [native observations](#native-observations).
