## Deliberate differences from the reference

| Area | User-visible consequence |
| --- | --- |
| Browser and operating system | Capture is available in the application and through the scoped API. Browser-reserved commands have alternatives. System-wide hotkeys, Apple widgets, Siri, Spotlight, Watch, Apple Intelligence, native calendar access and existing Omni Automation plug-ins each have a recorded boundary or adapter option. The installable window and persistent offline editing have separate acceptance gates. [Native and browser boundaries](FEATURE_PARITY.md) |
| Workspaces, online coordination and conflicts | Each login owns a private collection. Explicit shared membership adds collaborative task state. Concurrent editors can receive a visible version conflict and recover their draft. |
| Encryption and sync | This deployment trusts its server/database operator. Transport, host protection and encrypted off-host backups support that model. There is no proprietary Omni sync interchange. The reference's sync encryption is documented separately. [Omni encryption FAQ](https://support.omnigroup.com/omnifocus-encryption-faq/) |
| Files and portability | SQL stores file bodies. Native source backups have no promised interchange contract. The user can inspect import losses and restore this application's versioned export into a clean destination. |
| Identity and expression | Build original visuals, names, code, icons and explanatory material. Review the chosen brand, assets and dependency licenses before public distribution.
