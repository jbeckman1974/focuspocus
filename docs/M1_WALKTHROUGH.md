# Try the sample outline

Use the [Mac container commands](../README.md#run-the-sample-on-an-apple-silicon-mac). Record the commit, browser version and the container’s reported architecture. Task changes live in memory. Reloading or resetting the workspace returns to the sample.

1. Open Inbox. Capture “Bench kit”, then paste “Cable roll” and “Field book” on separate lines and submit. Select the latter two actions and indent them under Bench kit. The parent keeps its identity when it becomes a group.
2. In the inspector, apply the Field tag to the two selected actions. Set a due date on Field book. Rename it inline. Begin another rename and cancel it. Check its saved title, current selection and scroll position.
3. Collapse Bench kit, expand it, and move it to Punch list. Open the Field tag in the sidebar and find both children. Return to Punch list. Complete Bench kit, undo, then redo. Check that the same children, tag and date are still present.
4. Run once using only the keyboard, then reset the sample and repeat by pointer. With focus in the task tree, arrows move the active row, Shift+arrows extend a selection, F2 edits, I and O indent/outdent, M opens the move chooser, X completes/reopens, U undoes and Shift+U redoes. The toolbar, inspector and project drop targets supply pointer controls. Use Tab to reach other panes and ? in the tree to open the command list.
5. Try the inspector open and closed. Resize the panes, switch editing preference, change appearance and text size, then try a narrow window. Record any shortcut that conflicted, extra step, lost draft, unexpected scroll or focus change, and which editing mode you prefer.
